# Website background options

Created with the built-in image generation tool. Original generated PNG files. The website serves copies from `apps/web/public/backgrounds`, applied through `AppShell.tsx` and `globals.css` with a 62–72% cream overlay. Cards and controls retain their existing backgrounds. The login illustration uses a dark green overlay.

Applied placements:
- memories-v1.png: My Biographies or the welcome page.
- garden-v1.png: Style Lab; use behind opaque cards or with a cream overlay for readability.
- conversation-v1.png: Interview Studio.
