# Crop photos to 16:9

Choose **Crop / resize to 16:9** from an uploaded photo's Media Library preview, an interview's material list, the Screenplay Editor's supporting materials, or a Cinema Studio reference photo.

The editor shows a fixed 16:9 preview. Adjust **Zoom**, **Horizontal position**, and **Vertical position** to choose what stays in the frame. Expand **View original** to compare the full photo.

**Original crop resolution (no enlargement)** is the default. The crop uses original source pixels, with dimensions rounded down to whole 16-by-9 multiples for an exact aspect ratio. Changing zoom reduces the number of retained pixels. The displayed preview is smaller for convenience; it is never used as the source of the saved file. Optional outputs are 1280×720, 1920×1080 and 3840×2160; selecting one explicitly resizes the crop, including enlargement if necessary.

**Save cropped copy** creates a separate, ready-to-use JPEG in the same biography's Media Library with a thumbnail, checksum, source linkage and crop settings. Originals, approved interviews and saved screenplay snapshots are not overwritten. EXIF orientation is applied before cropping; transparent areas export against white. The crop can also be downloaded.

For interviews and screenplays, select/attach the new copy using the existing material picker. In Cinema Studio, saving a crop selects it for that photo's next generation; **Use original photo** restores the source. Cropped references are copied into the generation attempt's archive so later changes or deletion of the library copy cannot change an existing attempt. Original material IDs and the interview UID remain traceable.

Existing images can be cropped without re-uploading. Processing must finish before opening a Media Library photo. Access follows the source project's permissions; each scope verifies the selected photo belongs to that project, interview, screenplay or cinema production.
